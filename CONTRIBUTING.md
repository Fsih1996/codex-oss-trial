# Contributing / 参与贡献

## 中文

感谢你对这个项目感兴趣！这是一个初学者的学习项目，欢迎任何大小的改进，也欢迎提问。

1. Fork 本仓库并克隆到本地。
2. 新建分支：`git checkout -b my-change`
3. 修改代码，并尽量补充测试。
4. 运行测试：`pip install pytest && pytest`
5. 提交并发起 Pull Request，简单说明你改了什么。

遇到问题或有想法，可以直接开一个 Issue。请保持友善和耐心。

## English

Thanks for your interest! This is a beginner's learning project. Changes of any size are welcome, and so are questions.

1. Fork this repo and clone it.
2. Create a branch: `git checkout -b my-change`
3. Make your change and add tests if you can.
4. Run the tests: `pip install pytest && pytest`
5. Commit and open a Pull Request with a short description.

Have a question or idea? Open an Issue. Please be kind and patient.
