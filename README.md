# codex-oss-trial

Early personal open-source trial — beginner learning OSS workflows.

## English

Hello! This is a small public repository I made while learning how open source works.

I am a beginner. This repo is a practice space for:

- writing a README
- adding a license (MIT)
- making a first commit
- keeping a project public so others can read it

There is a tiny Python script, `hello.py`, that prints a greeting and today's date.

Contributions, questions, and kind feedback are welcome. Please be patient — I am still learning.

## 中文

你好！这是我在学习开源流程时创建的一个小型公开仓库。

我是初学者。这个仓库用来练习：

- 编写 README
- 添加开源许可证（MIT）
- 完成第一次提交
- 把项目公开，方便别人阅读

仓库里有一个很小的 Python 脚本 `hello.py`，会打印问候语和今天的日期。

欢迎提问和友善的反馈。请多包涵，我还在学习中。
